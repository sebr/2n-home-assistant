# 2N Intercom for Home Assistant

Home Assistant custom integration for [2N](https://www.2n.com) IP intercoms
(IP Verso, IP Style, IP Solo, IP Base, IP Force, IP Safety, IP Uni, …) using the
local [2N HTTP API (HAPI)](https://wiki.2n.com/hip/hapi/latest/en).

> Full documentation will land here as the integration is built out.
